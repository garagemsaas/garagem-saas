# Comercial — Plataforma Automotiva

A venda é direta para cada empresa. Combinar escopo, módulos, identidade, implantação e suporte, criar empresa e OWNER pelo bootstrap e entregar acesso. Não há planos self-service, cotas por plano ou checkout.

A página `/institucional` apresenta o módulo OFICINA e a contratação direta; `/ajuda` explica os fluxos disponíveis. REVENDA é somente fundação arquitetural nesta fase.

Vídeo, slides e imagens da marca anterior foram retirados de `frontend/public` e preservados em `docs/archive/materiais-fase7`. Não são mais distribuídos no build. Novos materiais devem ser gravados após aprovação da identidade comercial. O script antigo de gravação também é histórico.

Ver [provisionamento](../../operations/provisionamento-empresa.md) e [modelo da empresa](../../architecture/empresa-white-label.md).
